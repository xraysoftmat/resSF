# resSF
Resonant structure factors


[![PyPI version](https://img.shields.io/pypi/v/resSF.svg)](https://pypi.org/project/resSF) [![coveralls](https://coveralls.io/repos/github/xraysoftmat/resSF/badge.svg)](https://coveralls.io/github/xraysoftmat/resSF)


The package is designed to simplify resonant scattering calculations for crystallographic and diffraction studies, providing efficient workflows for:

- Energy-dependent resonant structure factor calculations
- Resonant and non-resonant scattering contributions
- Reflection-specific calculations
- Energy scans across absorption edges
- Integration into diffraction and synchrotron data analysis pipelines

---

## Installation

### From PyPI

```bash
pip install resSF
```

### Development Installation

```bash
git clone https://github.com/xraysoftmat/resSF.git
cd resSF
pip install -e .[dev]
```

---

## Features

✅ Resonant structure factor calculations

✅ Energy-dependent scattering amplitudes via [kkcalc2](https://github.com/xraysoftmat/kkcalc)

✅ Support for arbitrary reflections (hkl)

✅ Suitable for synchrotron and diffraction applications
